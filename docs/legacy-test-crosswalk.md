R3 must remove these markers after the integration corrections and retain the cases as ordinary passing regressions.

## Porting rule

Before deleting an old editor, model, parser adapter, or helper:

1. Record each old case as migrated, duplicate with a named canonical replacement, or deliberately changed with a rationale.
2. Keep expected fixtures independent from the new implementation. Do not derive old and new expected output from the same code.
3. Keep parser construction, browser behavior, collaboration/history, and benchmark tests in their correct roots. A passing file count does not establish behavior coverage.
